Classic SMS composer

Letters: press 2 once for A, twice for B, three times for C; wait 1 second to confirm. Numbers: each digit types itself, including 0. In letters mode, 0 = space. * = delete; # = confirm. Dial mode uses the same keys to make real DTMF tones. T9: one press per letter, * cycles predictions, 0 accepts word + space, # accepts word. Your numpad mapping applies in all modes.
